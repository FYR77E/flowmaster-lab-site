Как работаюHow I work

ИИ — рабочий инструмент, а не замена проверке. Для своих задач собрал систему из нескольких ИИ-агентов с правилами, разделением ролей и обязательным ревью.

AI is a working tool, not a substitute for checking. For my own work I built a system of several AI agents with shared rules, separate roles and mandatory review.

этап 01

stage 01

От требования к MVP

From requirement to MVP

Собираю требования, оцениваю реализуемость, пишу user stories и критерии приёмки, с Product Owner уточняю MVP и приоритеты.

I gather requirements, assess feasibility, write user stories and acceptance criteria, and agree MVP scope and priorities with the Product Owner.

этап 02

stage 02

Один делает — другой проверяет

One builds, another reviews

Изменения агентов идут через pull request и проверку агентом другой модели с вердиктом PASS, CONDITIONAL или REJECT; решения и их проверка записываются в журнал.

Agent changes go through pull requests reviewed by an agent on a different model, with a PASS, CONDITIONAL or REJECT verdict; decisions and their checks are logged.

этап 03

stage 03

Пилот и запуск

Pilot and rollout

Настраиваю тестовые стенды, проверяю оборудование, сопровождаю пилоты, веду статусы и риски, готовлю чек-листы тестирования и планы развёртывания.

I set up test environments, check the hardware, run pilots, track status and risks, and prepare test checklists and rollout plans.
