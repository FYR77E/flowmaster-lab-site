Как работаюApproach

ИИ — инструмент, а не замена проверке.AI is a tool, not a substitute for review.

Для своих задач собрал систему из нескольких ИИ-агентов с правилами, разделением ролей и обязательным ревью.

For my own work I built a setup of several AI agents with rules, separated roles and mandatory review.

  1. 01

    Сначала требованияRequirements first

    До того как что-то собирать, фиксирую задачу, user stories и критерии приёмки. По ним потом и проверяю результат.

    Before building anything I pin down the problem, user stories and acceptance criteria. Later I check the result against them.

  2. 02

    Один делает — другой проверяетOne builds, another reviews

    Изменения агентов идут через pull request и проверку агентом другой модели. Решения и вердикты записываются в журнал.

    Agent changes go through a pull request and a review by an agent on a different model. Decisions and verdicts are logged.

    PASSCONDITIONALREJECT

  3. 03

    Проверка на реальном оборудованииTested on real hardware

    Решение проходит тестовый стенд и пилот: проверяю оборудование, веду риски, готовлю чек-листы и план развёртывания.

    A solution goes through a test environment and a pilot: I check the hardware, track risks and prepare checklists and a rollout plan.
